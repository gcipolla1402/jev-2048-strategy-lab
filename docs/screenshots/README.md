# Checklist de screenshots

As imagens deste diretório devem ser capturadas da aplicação real. Não há screenshots incluídos nesta preparação porque uma captura autêntica exige a interface em execução e, para as telas de IA, dados produzidos por chamadas autorizadas ao JEV.

- [ ] `01-jogo-manual.png` — tabuleiro, placar, controles e histórico em modo manual.
- [ ] `02-autoplay-jev.png` — autoplay ativo com decisão, probabilidades, confiança e latência reais visíveis.
- [ ] `03-strategy-lab.png` — comparação BASIC/STRATEGIC e seletor de estratégia.
- [ ] `04-benchmarks-resultados.png` — execução ou histórico de benchmark com resultados reais.

## Como capturar

1. Execute backend e frontend conforme o README principal.
2. Use uma janela com largura mínima de 1440 px e zoom de 100%.
3. Não deixe a chave de API, o terminal com variáveis de ambiente ou dados pessoais visíveis.
4. Para telas com JEV, faça chamadas somente após autorizar o custo e confirme que os dados mostrados são reais.
5. Recorte apenas a janela da aplicação e salve os arquivos com os nomes acima.
6. Revise cada imagem antes de incluí-la no Git.

Depois das capturas, substitua a tabela de pendências da seção **Screenshots** do README por imagens relativas a este diretório.
